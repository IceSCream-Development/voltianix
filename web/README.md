# Voltianix Web ⚡

Aplicación web de Voltianix, desarrollada para la supervisión y gestión de flotas de vehículos eléctricos.

Esta interfaz permite a operadores y administradores visualizar el estado de las unidades en tiempo real, consultar métricas operativas y tomar decisiones basadas en información de ubicación, batería, autonomía y rutas.

## Objetivo

Proporcionar una experiencia visual clara e intuitiva para el monitoreo de flotas eléctricas dentro de un entorno de movilidad inteligente e Industria 4.0.

## Funcionalidades planeadas

- Visualización de unidades en mapa interactivo.
- Filtrado por estado operativo.
- Monitoreo de batería y autonomía.
- Consulta de detalles por unidad.
- Visualización de rutas.
- Recomendación de centros de carga.
- Dashboard de indicadores operativos.

## Stack Tecnológico

- Astro
- React
- Tailwind CSS
- OpenStreetMap
- Leaflet
